# VISITRA — Smart Visitor Management & Digital Pass System (MERN Stack) - Assignment 9

**VISITRA** is an enterprise-grade digital visitor management system built with **MongoDB**, **Express.js**, **React.js**, and **Node.js**.

---

## ⚡ Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Start VISITRA Server
npm start
```

Open `http://localhost:3000/` in your browser to launch the web application.

---

## 🚀 Key Features

1. **Role-Based Access Control (RBAC)**: Switch between `ADMIN`, `SECURITY`, `EMPLOYEE`, and `VISITOR` roles.
2. **Visitor Pre-Registration**: Form for scheduling visits and auto-generating digital pass badges.
3. **QR Pass Generator**: Encrypted QR code tokens for security verification.
4. **Gatekeeper Scanner**: Fast check-in and check-out scanning with entry validation.
5. **Host Appointments Workflow**: Employees can approve or reject visitor appointment requests.
6. **Analytics & Audit Logs**: Metrics dashboard, check-in log history, and downloadable CSV reports.
