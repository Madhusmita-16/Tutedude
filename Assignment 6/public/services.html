🛠️ Core Capabilities

Server Services & Architecture

Our custom Node.js HTTP web server provides high-performance, non-blocking static file serving, route dispatching, and automated MIME header resolution.

🚀

Asynchronous I/O Stream

Loads HTML templates and CSS stylesheets asynchronously using fs.readFile streams, ensuring zero blocking on the single-threaded event loop.

fs.readFile Module
🔀

Route Dispatcher

Maps clean URL paths like /home, /about, /services, and /contact directly to target public template files.

http & url Modules
🏷️

MIME Header Resolver

Automatically inspects file extensions to send proper HTTP headers such as text/html, text/css, and application/json.

Content-Type Headers
🛡️

Graceful 404 Handling

Intercepts missing files or invalid routes and dispatches a custom styled 404 HTML template with an HTTP status code of 404.

HTTP 404 Status
📊

Real-Time Request Logger

Logs incoming HTTP methods, requested URI pathnames, and exact timestamps to stdout for easy monitoring and debugging.

Console Middleware
🔒

Security & Error Fallbacks

Prevents directory traversal attacks by constraining file resolution strictly inside the designated public/ directory.

Path Normalization
