📖 System Architecture

About Our Node.js Web Server

Learn how this server processes client HTTP requests, resolves routes asynchronously, sets MIME headers, and handles HTTP response codes without third-party frameworks.

🧠

Core Node.js Engine

Constructed exclusively using built-in modules: http for connection handling, fs for non-blocking file access, and path for secure path resolving.

⚡

Non-Blocking Execution

Employs asynchronous callbacks so the main event loop remains free to process concurrent HTTP requests efficiently under server load.

🎯

Standardized Status Codes

Correctly dispatches HTTP status codes: 200 OK for successful file serving, 404 Not Found for invalid routes, and 500 Server Error for file exceptions.

🔄 Request Lifecycle & Flow Execution

1

HTTP Client Request

The browser sends an HTTP GET request (e.g. GET /about or GET /style.css) to port 3000.

2

URL Parsing & Route Matching

The server parses the request URL using Node's url module and matches the pathname against the route dictionary.

3

Asynchronous File Read

If the route or static asset exists, fs.readFile streams the file contents asynchronously from the filesystem.

4

MIME Header & Response Emission

The server sets the HTTP header (e.g. Content-Type: text/html) and sends the status code along with the page payload.
